# 🛡️ Pixel Tanks Battlefront

Клієнтська частина дипломного проєкту (Front-End) — 2D гра в жанрі танкового бою, реалізована на HTML, CSS та JavaScript.

🎮 Особливості гри

- 🎯 2D танковий бій
- 🧍‍♂️ Авторизація та профілі користувачів
- 🗺️ Вибір рівнів, динамічне завантаження карт
- 💣 Постріли, знищення бази, ворожі танки
- ⏱️ Таймер гри, лічильник ворогів, HUD
- 📊 Таблиця лідерів, звіт про баги
- 🎵 Вбудований музичний плеєр

🛠️ Технології

- **Front-end:** HTML5, CSS3 (неонова стилістика), JavaScript (ES6)

📂 Структура проєкту
├── static/                  # Файли: CSS, JS, Images, Audio
│   ├── CSS/
│   ├── JavaScript/
│   ├── Images/
│   └── Audio/

├── installation.txt         # Список залежностей
└── README.md                # Цей файл
